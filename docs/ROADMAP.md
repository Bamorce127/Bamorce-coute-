# Feuille de route de développement

## P0 — Fondation
- [x] Initialisation du dépôt et de la branche de travail
- [x] Application Next.js / TypeScript initiale
- [x] Première page responsive en français
- [x] Permissions typées et tests unitaires de base
- [x] Première migration PostgreSQL en accès fermé par défaut
- [x] Documentation sécurité et architecture
- [x] CI GitHub Actions
- [ ] Exécuter la CI sur GitHub et corriger chaque échec
- [ ] Revue de la migration et des permissions PostgreSQL
- [ ] Créer les environnements de développement dédiés

## P1 — Comptes et témoignages
- Authentification et récupération de compte
- Soumission de témoignages sans compte via référence et secret haché
- Flux texte, vocal, pièces jointes sécurisées
- Confidentialité anonyme / pseudonyme / privé
- File de modération et journal des décisions
- Tests d'autorisation négatifs

## P2 — Communauté et urgence
- Commentaires, réponses, réactions, blocages et signalements
- Centre Urgence, ressources locales vérifiées et protocoles humains
- Notifications internes
- Console modération et conformité

## P3 — Écoute et contenu
- Listeners formés et supervision
- Groupes thématiques modérés
- Bibliothèque de ressources
- Journal privé et outils d'auto-accompagnement

## P4 — Lives et revenus
- Lives audio/vidéo modérés
- Dons et cadeaux via prestataires autorisés
- Reçus, rapprochement, remboursements et anti-fraude
- Monétisation éthique et rapports transparents

## P5 — Production
- Tests E2E, tests d'intrusion et audit indépendant
- Revue juridique Côte d'Ivoire / pays ciblés / RGPD selon applicabilité
- Plan de continuité, sauvegarde/restauration et réponse aux incidents
- Déploiement progressif après validation explicite
